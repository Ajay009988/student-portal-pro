# 🎓 Student Management Portal - Django

A complete Student Management System built with Django where Admin can manage all students and normal users can manage only their own data.

### 🚀 Features
- 🔐 User Authentication (Login / Register / Logout)
- 👑 Admin vs Normal User Role (Admin - Sabka Data Dekhega)
- 👨‍🎓 Add, View, Search, Delete Students
- 🖼️ Photo Upload with Circular Profile View
- 🔍 Real-time Search by Name
- 📱 Fully Responsive - Mobile & Desktop (Bootstrap 5)

### 🛠️ Tech Stack
- **Backend:** Python, Django
- **Frontend:** HTML, Bootstrap 5, CSS
- **Database:** SQLite3
- **Auth:** Django Built-in Auth System
